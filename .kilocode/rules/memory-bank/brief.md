# Inference Engine Library Brief

Inference Engine Library is a cross-platform .NET inference foundation for AI agents and AI-powered applications. It provides a generic engine contract, a reusable ONNX Runtime base implementation, and a concrete vision example for object detection. The project focuses on predictable inference workflows, hardware acceleration where available, and clean extension points for custom model pipelines.

Key value delivered:

- Standardized inference contract for varied input and output types.
- Reusable lifecycle for model load, warmup, prediction, and disposal.
- Cross-platform execution with GPU acceleration support and CPU fallback.
- Practical reference implementation for image detection and post-processing.
- Test suite covering options, coordinate transforms, NMS behavior, and integration flows.
